Thermo RAW to mzML Converter

Batch-convert Thermo .raw files to .mzML on Windows. No Python or installation needed.

Download for Windows (.exe)

All releases · Source code

How to use

  1. Download and run RAW_mzML_Converter.exe.
  2. Click Add RAW Files or Add Folder.
  3. Choose an output folder and options (indexed mzML, GZip, peak picking, MS level, metadata).
  4. Click Convert. Output is written to the chosen folder (default mzMLfiles).
Windows SmartScreen: the app is not code-signed, so Windows may show "Windows protected your PC". Click More info → Run anyway.

Notes

Conversion is performed locally by ThermoRawFileParser (Apache-2.0, CompOmics), which uses Thermo Fisher Scientific's RawFileReader libraries under their own license. Your data never leaves your computer. If used in published work, please cite Hulstaert et al., J. Proteome Res. 2020, 19(1), 537–542, doi:10.1021/acs.jproteome.9b00328.
